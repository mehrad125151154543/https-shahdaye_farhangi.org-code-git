# سایت برنامهٔ هفتگی مدرسه

نرم‌افزار بدون وابستگی (Node.js + SQLite داخلی). سه نقش: مدیر، معلم، دانش‌آموز.

## اجرا روی کامپیوتر یا سرور
1. Node.js نسخهٔ **۲۲٫۱۳ یا بالاتر** را نصب کنید (https://nodejs.org). با `node -v` بررسی کنید.
2. در پوشهٔ پروژه اجرا کنید:  `node server.js`
3. مرورگر را روی http://127.0.0.1:3000 باز کنید.
4. بار اول فرم «ساخت حساب مدیر» می‌آید (رمز حداقل ۸ نویسه). بعد از آن مدیر کلاس‌ها و کاربران را می‌سازد.

دیتابیس خودکار در `data/school.db` ساخته می‌شود. برای پشتیبان‌گیری همین فایل (و `school.db-wal` و `school.db-shm` در صورت وجود) را کپی کنید.

## اجرا برای دسترسی دیگران (اینترنت یا شبکهٔ مدرسه)
- متغیرهای محیطی: `PORT` (پیش‌فرض 3000)، `HOST` (پیش‌فرض 127.0.0.1؛ برای شبکهٔ داخلی `0.0.0.0`).
- **حتماً پشت HTTPS اجرا کنید** (مثلاً Nginx یا Caddy به‌عنوان reverse proxy). در این حالت `COOKIE_SECURE=1` را بگذارید و اگر پشت پروکسی هستید `TRUST_PROXY=1` (برای محدودیت تلاش ورود بر اساس IP واقعی).
- برای اجرای دائمی از `pm2` یا سرویس `systemd` استفاده کنید.

## قبل از انتشار
- در ابتدای `public/app.js` نام قانونی، آدرس و راه تماس مدرسه را در `BIZ` بنویسید و بخش‌های [تکمیل شود] را با وکیل نهایی کنید.
- متن‌های حقوقی پیش‌نویس‌اند و جایگزین مشاورهٔ حقوقی نیستند.

## نکات امنیتی
- رمزها با scrypt و نمک تصادفی ذخیره می‌شوند و هیچ‌جا قابل مشاهده نیستند؛ مدیر فقط می‌تواند رمز جدید بسازد (یک بار نمایش داده می‌شود).
- نشست با کوکی HttpOnly، اعتبار ۱۲ ساعت، و محدودیت تلاش ورود. کنترل نقش‌ها سمت سرور است و دانش‌آموز فقط داده‌های کلاس خودش را از سرور می‌گیرد.
- فراموش‌شدن رمز مدیر: فایل دیتابیس را پشتیبان بگیرید و حساب مدیر جدید باید با حذف کاربران از دیتابیس یا ابزار sqlite ساخته شود.


## نسخه با طراحی جدید
رابط کاربری در `public/index.html` و `public/style.css` بازطراحی شده است. منطق برنامه و API در `public/app.js` و `server.js` حفظ شده‌اند.

برای اجرا:
1. Node.js نسخه 22.13 یا بالاتر را نصب کنید.
2. در ترمینال، وارد پوشه اصلی پروژه شوید.
3. اجرا کنید: `node server.js`
4. مرورگر: `http://127.0.0.1:3000`

برای اجرای دوباره، همان دستور را در پوشه اصلی پروژه اجرا کنید. دیتابیس در اولین اجرا به‌صورت خودکار در پوشه `data` ساخته می‌شود.
